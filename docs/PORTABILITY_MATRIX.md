## Promotion rule

Standardize engineering **structure**, not product authority semantics.

The shared kit may define how authority impact and evidence level must be explicit, but the target repository defines what those authority domains and evidence sources actually are.

## Fifth-pilot result

ORBI Edge Mesh strengthens three cross-project principles:

1. CI must declare what external/local/physical evidence it does **not** prove.
2. evidence levels such as identity, trust, capability advertisement and physical verification must not be collapsed.
3. context-budget optimization must preserve safety/authority invariants even when detailed procedures remain conditional.

Edge-specific physical-evidence, pairing/trust, resource-policy and node-routing skills remain project/domain patterns, not shared core skills.

The shared four-skill core remains unchanged.
