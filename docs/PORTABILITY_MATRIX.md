## Promotion rule

Standardize engineering **structure**, not product authority semantics.

The shared kit may define how authority impact must be explicit, but the target repository defines what those authority domains actually are.

## Fourth-pilot result

ORBI News confirms two cross-project principles:

1. CI must declare what external/local evidence it does **not** prove.
2. conditional domain skills scale better than adding more universal always-loaded skills.

News-specific factual-verification and publication-authority skills remain project/domain patterns, not shared core skills.
