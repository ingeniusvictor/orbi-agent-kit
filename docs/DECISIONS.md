# Decisions

## D-001 — ORBI owns the adaptation layer

ECC remains upstream reference material. ORBI project skills and authority boundaries remain ORBI-owned.

## D-002 — No full install in v0.1

The kit distributes a small proven core, not every ECC agent/skill.

## D-003 — Repository evidence is canonical

Git, tests, deterministic certification and governed documents outrank memory/model summaries.

## D-004 — Scanner baselines are repository-specific

Creative Studio, PVMetrics and L.U.M.I.A. each independently observed npm integrity SHA512 false positives. This does not authorize globally ignoring the detector.

## D-005 — Runtime autonomy stays out of the core

Hooks, MCP, memory, continuous learning, autonomous loops and multi-agent roles remain opt-in future experiments.
