# ORBI Selective Adoption Protocol

Use this sequence for a new ORBI repository.

## A0 — Inventory

Record current branch/HEAD, stack, package manager, tests, CI, trust boundaries, runtime/hardware dependencies and frozen/historical surfaces.

## A1 — Root instructions

Adapt `templates/AGENTS.template.md`. Never copy another product's authority model verbatim.

## A2 — Security baseline

Install a report-only, SHA-pinned AgentShield workflow. Create a **fresh repository-specific baseline**. No inherited exceptions.

## A3 — DAILY / LIBRARY classification

Use repository evidence to decide what should be always-available versus on-demand. Do not load every upstream skill.

## A4 — Verification skill

Adapt the generic verification skill to the repository's real commands and evidence model.

## A5 — Security/authority skill

Adapt trust boundaries, secrets, network/files/processes, identity/biometric/OT/data rules as applicable.

## A6 — Context budget

Keep invariant instructions small and domain procedures discoverable/on-demand. Do not remove safety guidance solely to clear a size flag.

## A7 — Agent harness

Define narrow action spaces, structured observations, safe retry and stop conditions. Validation of observation shape is **not** authorization.

## A8 — Certification

Certify final HEAD with repository CI + security evidence. Record rollback.

## Only after certification

Evaluate memory, hooks, MCP, continuous learning, autonomous loops or multi-agent roles as **separate experiments**.
